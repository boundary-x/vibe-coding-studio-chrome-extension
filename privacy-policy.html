개인정보처리방침

2026년 9월 1일:

"MakeCode 바이브코딩 브릿지"(이하 "본 확장 프로그램")는 바운더리엑스(Boundary X)가 제공하는 Chrome 확장 프로그램으로, 사용자가 자연어로 입력한 내용을 바탕으로 Microsoft MakeCode for micro:bit용 코드를 생성하고, 이를 자동으로 MakeCode 편집기에 반영하는 기능을 제공합니다.

수집하는 정보

본 확장 프로그램은 사용자의 개인정보를 수집, 저장, 판매하지 않습니다. 사용자가 사이드패널에 입력하는 프롬프트(코딩 요청 문구)는 코드 생성을 위해 바운더리엑스가 운영하는 백엔드로 전송되며, 별도로 저장되거나 제3자와 공유되지 않습니다.

사용자가 입력하는 접속키(API Key)는 백엔드 인증 목적으로만 사용되며, 확장 프로그램 자체에는 저장되지 않고 매 요청 시 함께 전송됩니다.

권한 사용 목적

  • tabs, scripting: 열려있는 makecode.microbit.org 탭을 찾아 생성된 코드를 자동으로 반영하고 블록으로 변환하기 위해 사용됩니다.
  • sidePanel: 채팅 인터페이스를 브라우저 사이드패널 형태로 표시하기 위해 사용됩니다.
  • host_permissions (makecode.microbit.org): 위 tabs/scripting 권한이 실제로 동작하는 대상 사이트를 makecode.microbit.org로 한정하기 위해 사용됩니다.

본 확장 프로그램은 makecode.microbit.org 외의 어떠한 웹사이트의 콘텐츠도 읽거나 수정하지 않습니다.

제3자 제공

수집되는 개인정보가 없으므로 제3자에게 제공되는 정보도 없습니다. 사용자가 입력한 프롬프트는 코드 생성을 위해 바운더리엑스가 운영하는 자체 백엔드(Google Cloud Functions)로만 전송됩니다.
