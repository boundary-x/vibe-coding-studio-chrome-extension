개인정보처리방침

시행일: 2026년 11월 19일

MakeCode 바이브코딩 브릿지는 바운더리엑스(Boundary X)가 제공하는 교육용 Chrome 확장 프로그램입니다. 사용자의 요청에 따라 MakeCode 코드 생성·수정·오류 해결·설명과 블록 강조 및 흐름도를 제공합니다.

처리하는 정보와 목적

  • 사용자가 입력한 코딩 요청, 설명 요청 및 대화 맥락: AI 응답 생성에 사용합니다.
  • 열려 있는 makecode.microbit.org 프로젝트의 코드, 오류 정보와 블록의 이름·값·연결 식별자: 기존 코드 수정, 오류 해결, 코드 설명 및 실제 블록 연결에 사용합니다. 요청한 기능에 필요한 정보를 AI 처리용 백엔드로 전송합니다.
  • 수업용 접속키: 바운더리엑스 백엔드에 전송하여 서비스 이용 권한을 검증합니다.

이름·이메일·연락처 등 개인정보를 입력하도록 요구하지 않습니다. 코딩 요청이나 코드에 비밀번호, 개인 API 키 또는 학생의 개인정보를 입력하지 마세요. 다른 웹사이트의 콘텐츠나 방문 기록을 AI 처리 목적으로 수집하지 않습니다.

전송 경로와 외부 서비스

요청과 필요한 코드·블록 정보는 HTTPS로 바운더리엑스의 Google Cloud Run 백엔드에 전송됩니다. 백엔드는 코드 생성과 설명을 위해 Anthropic Claude API로 요청 내용을 전달하며, AI 응답을 확장 프로그램에 반환합니다. 수업용 접속키는 백엔드 인증에 사용되며 Claude 프롬프트에 포함하지 않습니다.

Google Cloud 및 Anthropic의 서비스 운영과 데이터 처리는 해당 제공업체의 계약·정책을 따릅니다. Google Cloud 개인정보 안내 및 Anthropic 개인정보 안내에서 관련 내용을 확인할 수 있습니다.

저장과 이용 제한

확장 프로그램은 접속키와 대화 내용을 실행 중 메모리에서 처리하며, 이를 확장 프로그램의 영구 저장소에 저장하지 않습니다. 패널을 닫거나 다시 열면 초기화될 수 있습니다. MakeCode 프로젝트 저장은 MakeCode의 기능과 정책에 따릅니다.

사용자 데이터를 판매하거나 광고·신용평가 목적으로 사용하지 않습니다. 전송된 데이터와 서비스 운영 기록의 보관·삭제에 관한 문의는 아래 연락처로 요청할 수 있습니다. 외부 서비스의 보관 및 삭제에는 각 제공업체의 정책이 적용됩니다.

권한 사용 목적

  • tabs: 작업할 MakeCode 탭을 찾고 선택합니다.
  • scripting: MakeCode의 코드를 읽고 반영하며, 블록 변환·오류 확인·블록 구조 읽기·선택한 블록 강조를 수행합니다.
  • sidePanel: 코딩 요청, 설명과 흐름도를 사이드패널에 표시합니다.
  • 호스트 권한 (makecode.microbit.org): 위 편집기 접근을 MakeCode 사이트로 한정합니다.
